📺 TV Folder Select

A free, lightweight folder picker for Android TV and Google TV.

Tired of apps that crash, redirect you to Google Play, or refuse to let you select a folder?

TV Folder Select is here to help!

✨ Features

- 📁 Folder Selection — Browse and select folders.
- 📺 TV-Friendly Interface — Designed for Android TV and Google TV.
- 🎮 Remote Control Support — Navigate with your TV remote.
- 🌍 20+ Languages — Multilingual interface.
- 🚀 Lightweight — Simple and fast.
- 💰 100% Free — No subscriptions or hidden payments.

📥 Installation

1. Download the APK from GitHub.
2. Install it on your Android TV.
3. Open an app that requires folder selection.
4. Select TV Folder Select if it appears as an available option.
5. Choose your folder.

📺 Compatibility

Designed for Android TV, Google TV, and Android-based TV boxes.

Compatibility may vary depending on your device and Android version.

🔒 Source Code & Licensing

TV Folder Select is distributed as a free APK.

The source code is not publicly available. The GitHub repository provides the compiled application only.

This project is not open-source.

❤️ Why This Project Exists

Many Android TV users struggle with folder selection because existing file managers crash, don't support their devices, or depend on unavailable Google services.

TV Folder Select was created to help solve that problem.

Free to use. Made to help people.
